# Personal-Library-Genre-Tracker
A Python application that ingests book data from a text file, stores it in an SQLite database, processes genre frequency using Python data structures, and exports a summary report.

## Features
- Ingests raw `.txt` data into SQLite (library.db)
- Processes database rows using Sets & Dictionaries
- Exports aggregated report summaries to library_summary.txt`
